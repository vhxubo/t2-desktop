# T2 Desktop：面向 2Libra 的第三方桌面客户端

大家好，这里介绍一款由个人开发者制作的 2Libra 第三方桌面客户端 **T2 Desktop**（Third Party 2Libra）。

应用支持 Windows、macOS 与 Linux，免费且开源。它以独立桌面窗口运行，无需在浏览器中反复切换标签页。需要特别说明的是，本应用为**非官方**客户端，与 2Libra 无隶属或合作关系；2Libra 仅提供账号授权与内容接口。

---

## 一、内容覆盖与功能范围

客户端内的所有内容均来自 2Libra 官方开放接口，目前已接通 **92 项**能力，涵盖内容浏览、账号管理、创作互动、金币功能与消息通知等主要场景：

| 场景 | 主要功能 |
| --- | --- |
| 内容浏览 | 浏览热门、最新、社区讨论与关注动态；查看帖子正文、评论及投票结果；查看用户主页、徽章、节点与合集；支持全站搜索、热门标签与评分榜；正文中的表情、图片与视频链接均可正常显示 |
| 账号管理 | 查看个人资料、发布的帖子、收藏与书签；查看粉丝与关注名单；查看通知、金币余额与流水、签到状态及盲盒进度；管理个人合集、头像与介绍 |
| 创作与互动 | 发布帖子与短动态、编辑内容、调整节点、追加附言、设置评论开关；参与投票、发表情表态、收藏帖子、为评论添加书签、关注用户；支持在发帖时设置隐藏内容 |
| 金币与高级功能 | 打赏、签到、佩戴徽章、解锁付费内容、为帖子金币池注资、参与竞猜、领取兑换码、开启或重掷盲盒；发表评论前可预估所需金币 |
| 消息与内容管理 | 实时接收通知，无需手动刷新；可按关键词设置提醒偏好，并依据用户、节点与关键词过滤不希望看到的内容 |

总体而言，网页端提供的常用功能，均可在这一桌面窗口中完成。

## 二、客户端的主要特色

**原生桌面体验。** 应用采用原生窗口而非网页容器，启动迅速，界面风格与操作系统保持一致；支持最小化至系统托盘常驻，通知以系统消息形式呈现。

**安全的登录方式。** 账号在浏览器中完成登录，客户端无法接触密码；登录状态存放于系统自带的凭据管理中。如需停止使用，可在 2Libra 的授权页面撤销授权，或直接在客户端内退出登录。

**稳定的弱网表现。** 翻页、刷新与通知在网络状况不佳时会自动重试，无需反复手动操作；已浏览的正文与金币数据会保存在本机，断网状态下仍可查看。草稿随写随存，关闭窗口后仍可继续编辑。

**完整的媒体浏览体验。** 正文与评论中的配图、动图和视频链接统一整理，支持连续翻阅；动图可正常播放，图片支持放大、拖动与另存。视频通过浏览器打开原页面观看，无需在客户端内嵌入播放器。

**创作与互动辅助。** 发表评论前可查看预计消耗的金币及更节省的徽章选择；发帖时可设置可见范围与隐藏内容；若发布时未选择节点，站点完成分类后页面会自动更新为正式节点与原文链接。

**快捷的命令中心。** 通过 Ctrl+K（macOS 为 ⌘+K）打开命令中心，可快速执行发帖、搜索与页面跳转等操作；常用命令支持收藏，快捷键可按个人习惯调整。

**问题排查支持。** 应用提供代理设置；遇到网络故障时，可查看请求记录，便于向开发者反馈具体问题。

## 三、可自定义的设置项

**外观与排版**：支持跟随系统或固定使用浅色、深色主题；正文字号、标题字号、行距、页面宽度与列表疏密均可调整，并提供「小 / 标准 / 大」等常用档位，设置可一键恢复默认。

**图片与媒体**：可设置为默认不加载图片、按需手动加载；动图自动播放可选择关闭。内置多家图床，也支持填写自有图床地址与 Token，并可上传测试图片验证可用性。缓存占用情况可随时查看与清理。

**网络代理**：提供跟随系统、手动指定与直连三种方式；手动模式支持填写账号密码及不使用代理的地址。

**信息流与导航**：支持按用户、节点、关键词过滤内容；侧栏入口的显示与排序可自行调整；最多可设置 8 个常用节点快捷入口；评论区支持临时只查看指定用户的发言，退出后恢复原有楼层结构。

**通知设置**：桌面提醒、提示音与未读角标可分别开关；回复、提及、打赏、关注等消息类型支持逐类设置；关键词可设为「包含时提醒」或「包含时不提醒」；另可配置免打扰时段，期间照常接收消息，仅暂停弹窗提醒。

**快捷键**：支持为命令录制自定义组合键，并提供冲突提示；可恢复单条或全部默认设置，常用命令会优先展示。

**更新设置**：可配置检查频率、是否接收测试版本、闲时自动下载以及下载加速入口。

**其它选项**：关闭窗口时可选择退出或最小化至托盘；可设置启动时自动签到、稍后再看条目打开后是否移除；设置支持一键重置，且不会影响登录状态与本地草稿。
